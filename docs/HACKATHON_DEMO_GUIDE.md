# 🏆 Smart Edu - Hackathon Demo Guide

This guide will help you give a flawless presentation to the judges by demonstrating both the **Student** and **Teacher** perspectives on a single laptop.

## 🚀 The Golden Rule: Separate Sessions
To show both points of view at once, you **must** use two different browser sessions. Otherwise, logging into one will log you out of the other.

*   **Window 1 (Teacher):** Open a standard browser window.
*   **Window 2 (Student):** Open an **Incognito / Private Window** (or a different browser like Edge/Firefox).

## 🎬 Step 2: The Demo Flow

### 1. The "Live Sync" Magic
*   **Teacher:** Navigate to **"Live Class"**.
*   **Student:** Navigate to **"Live Class"**.
*   **Action:** As the Teacher, draw a simple diagram or write "Welcome Students" on the whiteboard.
*   **Judging Point:** Show the judges how the Student's whiteboard updates **instantly** without refreshing.

### 2. Real-time Communication
*   **Student:** Type "Hello Ma'am, I have a question" in the chat.
*   **Teacher:** Show the message appearing. Reply back. 
*   **Judging Point:** Highlights the interactive nature of the Low-Bandwidth platform.

### 3. AI Co-Pilot (Teacher)
*   **Teacher:** Go to **"Co-Pilot"**. Enter a topic like "Array Operations". Click "Generate".
*   **Judging Point:** Explain how this helps teachers generate lesson plans or quizzes in seconds using AI.

### 4. Doubt Solving System
*   **Teacher:** Go to **"Doubt Slots"**. Click **"Add Custom Slot"** for today at a specific time.
*   **Student:** Go to **"Doubt Sessions"**. Select "Shruti Malde". The new slot appears. Click **"Book Slot"**.
*   **Judging Point:** Shows the full lifecycle from teacher availability to student booking.

## 💡 Pro-Tips for Judges
*   **Bandwidth Efficiency:** Mention that the leaderboard and chat use tiny JSON packets, making them work on slow 2G/3G connections.
